How it works: live editing and analysis in the workspace

  1. Agents connect to the running DEV workspace through the Fabric MCP server and the Power BI modeling MCP.
  2. Read metadata, list items, run DAX (EVALUATE) on live models and SQL on Lakehouse or SQL endpoints.
  3. Edit or create items through REST updateDefinition and other APIs, without pulling files locally.
  4. Test in the portal, then commit the workspace state to Azure DevOps (revert if needed).
Shared safety anchor. Live edits still follow the same review and promotion path: commit the validated DEV state, then promote by pull request.

  • Investigative analysis
